# 50-Image Verification Sample

This folder contains the validated 50-image public-domain verification sample.

Contents:

- `abstract/`, `botanical/`, `landscape/`, `photography/`, `australiana/`, `fashion/`: validated image files.
- `master_metadata.csv`: canonical metadata and provenance for each image.
- `shopify_products.csv`: Shopify product CSV with four size variants per artwork.
- `validation_report.json`: validation summary.

The Shopify `Image Src` field is blank by design because Shopify requires hosted image URLs; no public URLs were fabricated.
